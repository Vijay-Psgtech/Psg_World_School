# PSG World School

This repository contains source code for the official PSG WORLD SCHOOL website. The project is built with React + vite + TailwindCSS and deployed using Nginx inside Docker.

## 🎯 Features

### 🎨 Design System

- Clean, international look
- white, gold, blue palette with premium fonts
- Staggered animations with Framer Motion
- Fully responsive (mobile, tablet, desktop)
- Touch-friendly interface

## 🛠️ Tech Stack

- **Frontend:** React 19.2.0, Vite 7.2.2, Tailwind CSS 4.1.17
- **Animations:** Framer Motion 12.23.24
- **Icons:** Lucide React 0.554.0
- **Routing:** React Router DOM 7.9.6
- **Deployment:** Docker + Nginx (SPA routing)
